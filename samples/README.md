# 演示资料说明

本目录全部为人工构建的模拟/离线资料，不包含真实店铺数据、真实行业结论或实时竞品价格。可自由修改以练习研究流程，但不能当作生产表现或市场证据。

- `orders.csv`：19 行商品记录、16 个去重订单，2026 年 1—3 月模拟经营数据。
- `documents/`：关联产品说明与指标口径。
- `web/`：两个明确标注离线虚构的 HTML 页面，提供正文和表格供工具实际读取。
- `web_sources.json`：上述网页的检索清单及内容快照，URL 使用 `sample://`，不请求公网。
- `manifest.json`：默认问题、文件结构、预期统计值和数据来源说明。

销售额是订单行支付金额合计，订单量按订单 ID 去重。统计结果应来自 CSV 计算，文档中的预期值仅用于验收核对。
